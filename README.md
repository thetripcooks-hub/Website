# Trip Cooks — Website

The official marketing and booking website for **Trip Cooks**, a group travel planning service. Built with Next.js 14 App Router, TypeScript, Tailwind CSS, and Contentful as a headless CMS.

---

## Tech Stack

| Layer | Technology |
|---|---|
| Framework | Next.js 14 (App Router) |
| Language | TypeScript |
| Styling | Tailwind CSS + shadcn/ui |
| CMS | Contentful (GraphQL) |
| Payments | Stripe |
| Email | EmailJS |
| Video | Mux |
| Analytics | Vercel Analytics + Speed Insights |
| Deployment | Vercel |

---

## Project Structure

```
app/
  home/           # Landing page
  trips/          # Trip listing + detail pages ([id]/[name])
  private-trips/  # Private trip enquiry
  about/          # About page
  contact/        # Contact page
  legal/          # Privacy policy + Terms & Conditions
  cart/           # Booking cart
  checkout/       # Checkout flow
  payment-success/ # Post-payment confirmation
  robots.ts       # robots.txt (auto-generated by Next.js)
  sitemap.ts      # sitemap.xml (auto-generated, fetches trips from Contentful)

components/
  ui/             # Shared UI components (nav, footer, buttons, etc.)
  icons/          # SVG icon components

hooks/            # Custom React hooks
lib/              # Apollo client, utilities, dayjs config
queries/          # GraphQL queries (Contentful)
types/            # TypeScript type definitions
reports/          # SEO audit reports (see below)
```

## Getting Started

### 1. Install dependencies

```bash
npm install
# or
yarn
# or
pnpm i
# or
bun install
```

### 2. Configure environment variables

Create a `.env.local` file at the project root:

```bash
# Stripe
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=<value>
STRIPE_SECRET_KEY=<value>

# EmailJS
NEXT_PUBLIC_EMAIL_JS_KEY_PUBLIC_KEY=<value>
NEXT_PUBLIC_CONTACT_SERVICE_ID=<value>
NEXT_PUBLIC_PRIVATE_TRIP_SERVICE_ID=<value>
NEXT_PUBLIC_PRIVATE_TRIP_TEMPLATE_ID=<value>
NEXT_PUBLIC_CONTACT_TEMPLATE_ID=<value>

# Contentful
NEXT_PUBLIC_CONTENTFUL_SPACE_ID=<value>
NEXT_PUBLIC_CONTENTFUL_ACCESS_TOKEN=<value>
NEXT_PUBLIC_CONTENTFUL_PREVIEW_ACCESS_TOKEN=<value>

# Mux
MUX_TOKEN_ID=<value>
MUX_TOKEN_SECRET=<value>
```

### 3. Run the dev server

```bash
npm run dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## SEO

The following SEO features are implemented:

- **Per-page metadata** — every route exports `title`, `description`, `openGraph`, `twitter`, and `alternates.canonical`
- **Dynamic trip metadata** — `generateMetadata` in `app/trips/[id]/[name]/layout.tsx` fetches each trip from Contentful and generates unique OG tags and Twitter cards
- **JSON-LD structured data** — `Organization`, `WebSite`, and `TouristTrip` schemas injected via `<script type="application/ld+json">`
- **robots.txt** — auto-generated via `app/robots.ts`; blocks `/api/`, `/cart`, `/checkout`, `/payment-success`
- **sitemap.xml** — auto-generated via `app/sitemap.ts`; includes all static routes + every trip fetched from Contentful
- **No-index on transactional pages** — cart, checkout, and payment-success are excluded from search engine indexing

### SEO Reports

Audit reports are stored in the [`/reports`](./reports/) directory:

| File | Description |
|---|---|
| `seo-report.html / .pdf` | Initial SEO audit — issues found before fixes |
| `seo-report-2.html / .pdf` | Follow-up audit — after all SEO improvements were applied |
| `tripcooks-owner-report.html / .pdf` | Plain-English report for the business owner |
